# ZOS-API Documentation

This repository hosts the generated HTML documentation for the Zemax OpticStudio API (ZOS-API).

## Accessing the Documentation

The documentation is deployed using GitHub Pages and can be accessed online at:

[https://liuyazui.github.io/ZOS-API/](https://liuyazui.github.io/ZOS-API/)

## Project Structure

- The main content consists of HTML files generated from the ZOS-API source code, likely using a tool like Doxygen.
- Various supporting files (images, CSS, JavaScript) required for the documentation site are included.
- `index.html` serves as the main entry point for the documentation.

## Sitemap

A `sitemap.xml` file is included in the root directory to help search engines discover and index all the pages within this documentation site.

## Contributing

This repository primarily serves as a deployment target for the generated documentation. If you find issues with the documentation content itself, please refer to the official Zemax OpticStudio resources. If you encounter problems with the site structure or deployment, feel free to open an issue.
