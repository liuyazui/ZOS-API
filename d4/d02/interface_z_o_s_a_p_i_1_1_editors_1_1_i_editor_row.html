Detailed Description

Base interface for all five editor row types. General row information can be accessed via the IEditor interface. Note that this interface can be used to retrieve basic editor information only. For more detailed data, you should use one of the editor-specific interfaces:

ZOSAPI.Editors.LDE.ILDERow (from ZOSAPI.Editors.LDE.ILensDataEditor.GetSurfaceAt)

ZOSAPI.Editors.NCE.INCERow (from ZOSAPI.Editors.NCE.INonSeqEditor.GetObjectAt)

ZOSAPI.Editors.MFE.IMFERow (from ZOSAPI.Editors.MFE.IMeritFunctionEditor.GetOperandAt)

ZOSAPI.Editors.TDE.ITDERow (from ZOSAPI.Editors.TDE.IToleranceDataEditor.GetOperandAt)

ZOSAPI.Editors.MCE.IMCERow (from ZOSAPI.Editors.MCE.IMultiConfigEditor.GetOperandAt)
